# Recursos visuales

Cabecera y enlaces creados para el perfil de jhus. La tipografía de las piezas gráficas se convirtió a trazados; los SVG no solicitan fuentes ni recursos externos.

- **Space Grotesk**, de Florian Karsten: https://github.com/floriankarsten/space-grotesk y https://github.com/google/fonts/tree/main/ofl/spacegrotesk. Licencia SIL Open Font License 1.1, incluida en `SPACE-GROTESK-OFL.txt`.
- **Devicon**, iconos de los lenguajes, bases de datos, herramientas y plataformas del perfil: https://github.com/devicons/devicon. Licencia MIT, incluida en `DEVICON-LICENSE.txt`. Los iconos de Apple y Rust se adaptaron a un color claro para el fondo oscuro.
- **Metrics**, de https://github.com/lowlighter/metrics, bajo licencia MIT. El flujo de GitHub Actions está preparado para generar el panel con los datos públicos de esta cuenta.

El panel inicial es una representación propia de los datos públicos de GitHub consultados el 19 de octubre de 2026. Incluye la fecha de consulta y no usa datos de demostración. Metrics sustituirá ese SVG al activarse mediante el secreto `METRICS_TOKEN`.

Los nombres y logotipos de las tecnologías pertenecen a sus respectivos titulares. Se usan para identificar las herramientas del perfil, sin indicar afiliación ni patrocinio.
