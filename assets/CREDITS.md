# Presentación ASCII

El README actual contiene únicamente el bloque ASCII de jhus, con su presentación profesional. La tipografía pixel es VT323, de Peter Hull, distribuida bajo SIL Open Font License 1.1: https://github.com/google/fonts/tree/main/ofl/vt323 . Su licencia está incluida en VT323-OFL.txt. El texto se convirtió a trazados para conservar su apariencia en cualquier navegador.

El retrato se generó a partir del avatar público del usuario. La animación de terminal dispone de una alternativa sin movimiento y el cursor se detiene tras unos segundos. El bloque no consulta servicios externos. Los recursos anteriores que permanezcan en el repositorio no forman parte del README actual.
